## Client Objectives & Value

### Primary Objectives

- Modernize legacy Oracle PL/SQL packages by translating them into independent .NET REST microservices.
- Decouple business logic from the Oracle database.
- Build containerized microservices deployed on AWS EKS using Docker.
- Enable cloud-native architecture while preserving existing business functionality.
- Improve system resiliency through a modern microservices architecture.
- Support incremental migration using the Strangler Fig deployment pattern.

- Multi-region cloud resiliency
- Reduce dependency on Oracle database business logic
